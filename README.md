# Vahagn Papikyan - Portfolio

Single-file portfolio. No install needed.

## Run
Double-click `index.html` to open it in your browser.
(Optional local server: `npx serve .` or `python -m http.server`)

## Edit content
Open `index.html` in a text editor and change the `CONFIG` block near the
bottom (name, intro, roles, projects, technologies, journey, contact links).
Replace placeholders: GitHub links, email, LinkedIn, journey entries.

## Notes
- Not tested with Playwright or a production build.
- Uses the Bricolage Grotesque font from Google Fonts (falls back to system fonts offline).
